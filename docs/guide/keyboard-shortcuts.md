---
title: Keyboard shortcuts
sidebar_position: 21
description: The default keyboard and mouse bindings.
---

Press <kbd>?</kbd> in the editor, or open **Help → Keyboard Shortcuts**, for the complete list, which shows what each command is bound to now. The defaults below can be changed under **Settings → Shortcuts**; the mouse and the graph's own keys cannot.

| Keys | Action |
| --- | --- |
| Right-click / <kbd>Space</kbd> | Open the node menu |
| <kbd>Delete</kbd> | Delete the selection |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Undo / redo |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> / <kbd>Ctrl</kbd>+<kbd>O</kbd> | New project / open a project |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Save the project / save it as a new file |
| Arrow keys | Move the selected nodes |
| <kbd>F</kbd> | Frame the whole graph |
| <kbd>F10</kbd> | Go to the menu bar |
| <kbd>F1</kbd> | Open the user guide |
