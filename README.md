Welcome! This is the community home of **SST Material Forge**, a desktop editor for building tileable PBR materials from a graph of nodes. It holds the online documentation and is where you can report problems, suggest features and ask questions.

## 📖 Documentation

**[shadowshardtools.github.io/SST-Material-Forge-Docs](https://shadowshardtools.github.io/SST-Material-Forge-Docs/)**

- **[Guide](https://shadowshardtools.github.io/SST-Material-Forge-Docs/intro)**: from your first node to exporting maps for Unreal Engine, Unity, Godot and glTF.
- **[Node reference](https://shadowshardtools.github.io/SST-Material-Forge-Docs/nodes)**: every node, with its ports, settings, defaults and ranges.

Inside the editor, <kbd>F1</kbd> opens the same guide, and <kbd>?</kbd> lists your keyboard shortcuts.

## 🐞 Reporting a bug

Before opening a new issue, please [search the existing ones](https://github.com/ShadowShardTools/SST-Material-Forge-Docs/issues?q=is%3Aissue). Someone may have reported it already, and a 👍 on that issue helps us prioritise.

A good bug report includes:

1. **Your build details.** In the editor, open **Help → About SST Material Forge** and click **Copy build details**. This gives us your version, operating system, graphics engine and GPU, and it is always our first question.
2. **What you did**, step by step, and **what you expected** to happen.
3. **What happened instead.** Screenshots help a lot. If the editor showed an error, **Help → Report a Problem…** copies the details for you.
4. **A project file**, if the problem is in a particular material and you're happy to share it. A small `.sstpkg` with just the affected material is ideal.

> [!NOTE]
> Issues are public. Only attach projects, textures and screenshots you're comfortable sharing with everyone.

## 💡 Suggesting a feature

Ideas for new nodes, export presets, workflow improvements and anything else are welcome. Open an issue and tell us:

- what you were trying to make,
- what got in the way,
- how you imagine it working.

The problem you hit matters more to us than any particular solution, so describe it even if you don't have a fix in mind.

## ❓ Asking a question

Stuck on how to build something? Open an issue and describe what you're trying to achieve. A screenshot of your graph is often the quickest way to show it. Many questions also have an answer in the [guide](https://shadowshardtools.github.io/SST-Material-Forge-Docs/intro).

## ✏️ Found a mistake in the docs?

Please report it as an issue rather than a pull request. The guide and node reference are generated from the editor itself, so we fix the source and the site follows.

## ℹ️ About this repository

This repository contains the documentation site only. The editor's source code is not here. Notes for maintainers are in [MAINTAINING.md](MAINTAINING.md).
